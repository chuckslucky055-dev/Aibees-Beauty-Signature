# Aibees Beauty Signature

A beauty studio showcase and booking website concept featuring makeup, bridal hair, wigs, beauty essentials, a lookbook, training enquiries and appointment contact details.

**Live demo:** https://aibees-beauty-signature-6dttg7.v2.appdeploy.ai/

## Run locally

```bash
npm install
npm run dev
```
